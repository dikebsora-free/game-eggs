# VIAaaS
VIAaaS is the Minecraft plugin ViaVersion made standalone as a proxy.

More information is available here: https://github.com/ViaVersion/VIAaaS

## 服务器端口
The minecraft server requires a single port for access (默认值 25565), and one TCP port 25543, to be used for HTTPS and WebSocket connections.

| 端口 | 默认值 |
|------------|---------|
| 游戏 | 25565   |
| WS & HTTPS | 25543   |
