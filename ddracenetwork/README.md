# DDRaceNetwork

## From their [Website](https://ddnet.org/downloads/)

DDraceNetwork (DDNet) is an actively maintained version of DDRace, a Teeworlds modification with a unique cooperative gameplay..

## 安装/系统要求
|  | 最低要求 | 推荐 |
|---------|---------|---------|
| 处理器 | Almost any proccessor will work | -|
| 内存 | 100 MiB | 256 MiB |
| 存储 | 70 MiB | 1024 MiB |
| 网络 | Any reasonable speed |- |
| 游戏所有权 | Not needed | The game is free, and server doesn't need the game to work. |   

## 服务器端口

| 端口 | 默认值 |
|---------|---------|
| 游戏 | 8303    |
